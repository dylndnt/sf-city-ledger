# Civic report direction

The previous interface still borrowed the familiar dashboard recipe: an oversized display face, a round monogram, tinted cards, soft shadows, color-coded decoration, and many small uppercase labels. Those treatments compete with the public records the visitor came to inspect.

Use a municipal report as the visual reference. Keep the page white, the text dark, and the grid visible through thin rules. Use a single sans family, ordinary sentence case for most labels, and aligned tabular figures. The opening chart remains the main interaction. Its ribbons should be quiet enough that category names and amounts lead; color marks negative accounting entries and interactive focus.

The drilldown should read like connected ledger columns. Keep category order stable. Give the selected row a left rule and light paper tint, fade siblings by text contrast, and replace full-card fills with a thin proportional line. Breadcrumbs, totals, payees, and outcome measures use the same report vocabulary. Motion continues to indicate only newly entered columns.

Check the initial chart, a selected high-level category, a deep path, and the payee view at desktop and 390 px. Confirm no page-wide overflow, selected context stays visible, and the FY2024 comparisons remain readable.
